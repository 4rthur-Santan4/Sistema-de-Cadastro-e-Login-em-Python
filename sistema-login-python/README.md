# Sistema de Login em Python

## Sobre o projeto

Este projeto consiste em um sistema simples de cadastro e login desenvolvido em Python, com o objetivo de praticar lógica de programação e estruturas de dados.

## Funcionalidades

- Cadastro de usuários.
- Validação de nomes de usuário vazios ou duplicados.
- Validação de senha com no mínimo 8 caracteres.
- Confirmação de senha.
- Login com verificação de credenciais.
- Limite de três tentativas de senha por operação de login.
- Menu interativo com tratamento de opções inválidas.

## Tecnologias e conceitos

- Python
- Funções
- Dicionários
- Estruturas condicionais (`if`, `elif`, `else`)
- Laços de repetição (`while`)
- Validação de entradas

## Como executar

1. Instale o Python 3.
2. Baixe ou clone este repositório.
3. Abra o terminal na pasta do projeto.
4. Execute:

   `python main.py`

## Observações

Este é um projeto educacional. Os usuários são armazenados em memória e os dados são perdidos quando o programa é encerrado. As senhas são armazenadas em texto puro, portanto o sistema não deve ser utilizado para autenticação em aplicações reais.
